# KANSOKU v0.8.1

KANSOKU v0.8.1 adds a reproducible Ubuntu/containerlab validation environment for the v0.8 network-state model.

Highlights:

- FRRouting, Open vSwitch, nftables, client, and server containers
- live pcap acquisition and flow/configuration correlation
- container-scoped read-only collectors
- deterministic normal and fault scenarios
- Ubuntu bootstrap, macOS VM guide, Makefile workflow, and JSON reports
- improved nftables chain-order and conntrack-state matching
