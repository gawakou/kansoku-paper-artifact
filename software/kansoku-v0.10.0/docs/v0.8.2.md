# Version 0.8.2: reliable virtual-lab application services

The first live v0.8.1 deployment showed that L2/L3 connectivity could become ready while the background HTTP server launched from a containerlab bootstrap exec session was no longer listening. Version 0.8.2 separates network configuration from application service lifecycle management. The host script configures the server interface, while `lab-up.sh` starts HTTP and iperf3 through detached Docker exec processes and performs local and end-to-end readiness checks.
