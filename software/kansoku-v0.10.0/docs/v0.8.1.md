# Version 0.8.1: reproducible live virtual lab

Version 0.8.1 converts the v0.8 fixture-only network-state demonstration into a reproducible, running open-source network lab.

## Added

- Ubuntu VM bootstrap and cloud-init example
- containerlab topology with seven nodes
- FRRouting routers, Open vSwitch L2 devices, and nftables firewall
- real ping, HTTP, iperf3, pcap, and live state collection
- read-only `network collect --container` execution
- normal, firewall-deny, route-missing, VLAN-mismatch, and packet-loss tests
- JSON test reports and Makefile targets
- static lab self-test for CI environments without Docker privileges

## Design rule

KANSOKU runs outside the data-plane containers. Device commands are executed through a read-only container-runtime wrapper and are recorded as ordinary `CollectionRun` evidence. Fault injection remains isolated to disposable lab nodes.
