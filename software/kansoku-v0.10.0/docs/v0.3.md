# KANSOKU v0.3

Version 0.3 turns the v0.2 measurement pipeline into a profile-aware observation loop.

## Main changes

1. Target profiles are stored in SQLite and define expected bandwidth, RTT/loss thresholds, and normal/intensive observation intervals.
2. Throughput can be evaluated relative to expected bandwidth or a learned median baseline.
3. Ping, iperf3, simulation, and CSV replay automatically create state estimates unless `--no-auto-evaluate` is specified.
4. A transition from WARNING/DEGRADED/CRITICAL back to NORMAL creates a low-risk `restore_observation_rate` proposal.
5. Executed observation-rate proposals persist an `ObservationPlan` consumed by `agent watch`.
6. The dashboard shows the target profile, observation plan, state evidence, local time, time-series charts, proposals, and clickable raw collection runs.
7. Opening a v0.2 SQLite database automatically creates the new v0.3 tables without deleting existing measurements.

## Relative throughput evaluation

The reference is selected in this order:

1. learned `baseline_throughput_mbps`;
2. configured `expected_bandwidth_mbps`;
3. v0.2 absolute fallback thresholds when neither exists.

Default ratios are:

- NORMAL: at least 85% of the reference;
- WARNING: 70% to less than 85%;
- DEGRADED: 40% to less than 70%;
- CRITICAL: less than 40%.

## Example

```bash
kansoku --db ./kansoku.db profile set \
  --target 172.16.10.210 \
  --name "100 Mbps laboratory path" \
  --expected-bandwidth 100

kansoku --db ./kansoku.db agent ping \
  --target 172.16.10.210 --count 5

kansoku --db ./kansoku.db agent iperf3 \
  --target 172.16.10.210 --duration 10
```

The agent commands automatically evaluate the target after storing observations. For a 100 Mbps profile, approximately 94 Mbps is treated as NORMAL.

## Learned baseline

```bash
kansoku --db ./kansoku.db profile learn-baseline \
  --target 172.16.10.210 \
  --limit 20 \
  --minimum-samples 3
```

The median of successful normalized `throughput_mbps` observations is stored as the baseline.

## Observation watch

```bash
kansoku --db ./kansoku.db agent watch \
  --target 172.16.10.210 \
  --iterations 10 \
  --iperf3-every 5
```

Low-risk interval proposals are not applied automatically unless explicitly enabled:

```bash
kansoku --db ./kansoku.db agent watch \
  --target 172.16.10.210 \
  --auto-apply-low-risk
```

Route changes and high-risk actions remain outside this automatic path.
