# KANSOKU v0.2 implementation notes

## Measurement provenance

A normalized Observation is linked to its CollectionRun through `labels.run_id`.
The CollectionRun contains the command, timestamps, exit status, raw stdout/stderr, and measurement parameters.
This supports reproducibility and later replay or audit.

## Platform compatibility

`PingAgent` detects Darwin and Linux. macOS interprets `ping -W` in milliseconds, while Linux uses seconds. Both output-summary formats are parsed.

## iperf3 normalization

The Agent requests JSON output (`-J`) and normalizes TCP and UDP summaries. Raw JSON is preserved unchanged in the CollectionRun.

## Dashboard boundary

The dashboard is read-only. It does not expose action execution. This keeps visualization separate from KANSOKU Guard and Act authorization.
