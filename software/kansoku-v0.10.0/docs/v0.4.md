# KANSOKU v0.4 design

Version 0.4 completes the first safe-action lifecycle.

```text
Proposal
  -> Guard
  -> WAITING_APPROVAL when required
  -> Act (dry-run by default)
  -> Persist internal effect
  -> Verify postconditions
  -> Rollback on verification failure
  -> Persist final transaction
```

## Scope

v0.4 intentionally limits automatic execution to observation-rate changes. Route switching remains a simulation adapter. Linux `tc netem` is available only as an explicitly enabled test adapter.

## Outcomes

- `WAITING_APPROVAL`
- `REJECTED`
- `DRY_RUN`
- `VERIFIED`
- `INCONCLUSIVE`
- `ROLLED_BACK`
- `FAILED`
