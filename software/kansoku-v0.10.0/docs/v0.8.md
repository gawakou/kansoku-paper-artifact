# KANSOKU v0.8: vendor-neutral network state

v0.8 connects packet/flow evidence to the configuration and operational state of open-source routers, switches, and firewalls.

## Reference platforms

- FRRouting: interfaces and route tables;
- Open vSwitch: access/trunk ports, VLAN membership, and configured peer links;
- nftables: ordered firewall match/action rules and counters.

The import layer converts platform-specific JSON into stable KANSOKU entities: `NetworkDevice`, `NetworkInterface`, `VlanRecord`, `L2Link`, `RouteEntry`, `PolicyRule`, and `NetworkSnapshot`.

## Flow correlation

A directional `FlowRecord` can be evaluated against:

1. longest-prefix installed route selection;
2. ordered basic firewall-rule matching;
3. captured VLAN existence in the imported switch state.

The result is a persisted `FlowAssessment` with an explainable verdict: `ALLOW`, `DENY`, `UNROUTABLE`, or `UNKNOWN`.

This is intentionally a conservative reference evaluator. Complex stateful firewall semantics, NAT transformation chains, policy routing, recursive next-hop resolution, dynamic control-plane convergence, and vendor-specific behavior remain future work.

## Reproducible virtual lab

`scenarios/virtual-lab` contains deterministic FRR, OVS, and nftables JSON fixtures. They allow the complete import and correlation path to run without privileged containers or physical equipment. The same model is designed to accept read-only output from live open-source components.
